`aces-sdl` is now published to PyPI (`pip install aces-sdl`). Releases are cut from a single committed `__version__` literal, bumped from the towncrier changelog fragments by `tools/release.py` (`removed` → major once ≥ 1.0 else minor, `added`/`changed`/`deprecated` → minor, `security`/`fixed` → patch; `breaking` is recorded but forced manually). Merging the release PR to `main` builds the corpus-bundled wheel + sdist, publishes over OIDC trusted publishing, and attaches a CycloneDX SBOM to the GitHub Release.
