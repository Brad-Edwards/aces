`aces-sdl` is now published to PyPI (`pip install aces-sdl`). Releases are cut on promotion of `dev` to `main`, with the version derived from the towncrier changelog fragments as the single source of truth (`breaking`/`removed` → major, `added`/`changed`/`deprecated` → minor, `security`/`fixed` → patch). Each release publishes the corpus-bundled wheel + sdist over OIDC trusted publishing and attaches a CycloneDX SBOM to the GitHub Release.
