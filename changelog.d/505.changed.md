The criterion is meaning preservation: an error affects SDL meaning (structural/semantic invariants — reference resolution, uniqueness, ambiguity, acyclicity, required-profile guards, instantiation, explicit redaction), while an advisory is a deployability or quality heuristic that leaves SDL meaning intact, with a fail-closed default for borderline cases. `docs/explain/sdl/validation.md` now cites that single normative source instead of restating the rule, and a new AST drift-guard test enforces that the reference `SemanticValidator` keeps the advisory (`_warn_*`/`_collect_advisories`) and error (`_verify_*`/`_err`) channels separate.
