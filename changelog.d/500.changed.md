The published `instantiated-scenario-v1` contract now rejects unresolved `${var}` substitution tokens in string values — both whole-string placeholders (`"${os}"`) and embedded tokens (`"host-${index}"`) — differentiating it from `sdl-authoring-input-v1`, which still accepts them. The same invariant is enforced on the `InstantiatedScenario` model so directly constructed instances must be fully concrete.
