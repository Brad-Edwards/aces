# Cite RAES

Use this software citation when RAES contributes to your work:

```bibtex
@software{raes,
  author  = {Edwards, Brad},
  title   = {RAES: Reproducible Agentic Environments System},
  year    = {2026},
  license = {MIT},
  url     = {https://github.com/RAESystem/rae}
}
```

Also record the release or commit that you used. Name the contracts, profiles,
scenario, backend, and run evidence. These details show the limits of your
result better than the project name alone.
