# ACT-616 — Participant-Consumable Derived Context Views

## Statement

The ecosystem shall support participant-consumable derived operational context views over evolving state, including reachability, dependency, attack, detection, workload, and comparable operational perspectives.

## Rationale

Requirement inventory expansion. Many participant behaviors depend on derived context that must be expressible without tying the ecosystem to one computation strategy.
