# SYS-001 — RAES SDL Ecosystem

## Statement

The RAES ecosystem shall provide an implementation-agnostic foundation spanning language, processing, portable contracts, experiments, assurance, and governance for specifying, validating, compiling, executing, observing, and comparing cyber-range scenarios and experiments.

## Rationale

Current state: partially implemented. The ecosystem needs a coherent product-level foundation whose meaning and claims remain portable independent of any single implementation language, deployment environment, processor, or backend.
