# EXP-729 — Benchmark Reference Targets, Hidden Assets, And Gold Standards

## Statement

The ecosystem shall support first-class benchmark reference targets, hidden evaluation assets, and gold standards distinct from public task statements, verifier logic, and participant inputs.

## Rationale

Primary-source refresh shows that many benchmark protocols rely on hidden tests, gold answers, or comparable truth assets that must be modeled distinctly to preserve benchmark integrity.
