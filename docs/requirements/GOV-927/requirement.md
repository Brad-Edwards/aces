# GOV-927 — Release SBOM Publication

## Statement

The ecosystem shall publish software bills of materials for released packages, distributions, and deployable artifacts where downstream users or operators depend on release composition claims.

## Rationale

Imported from the superseded governance backlog before deleting the old governance repo. Release composition needs explicit evidence rather than relying on source tree inspection or package-manager metadata alone.
