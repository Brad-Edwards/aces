# EXP-730 — Human Review, Annotation, And Adjudication Assets

## Statement

The ecosystem shall support human-produced review, annotation, and adjudication assets for participant tasks, trajectories, outputs, and benchmark artifacts as first-class experiment assets.

## Rationale

Primary-source refresh shows that human-reviewed and human-annotated benchmark assets are common and should not be collapsed into generic metadata or automated verifier outputs.
