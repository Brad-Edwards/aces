# API-416 — Participant Benchmark, Verifier, And Reward Contracts

## Statement

The ecosystem shall define plain-data contracts for participant-oriented benchmark protocols, verifier outputs, judge outputs, and reward signals.

## Rationale

Primary-source refresh shows that benchmark, verifier, and reward components need portable external contracts if participant evaluation is to remain comparable across processors and backends.
