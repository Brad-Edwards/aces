# EXP-716 — Experiment Metadata And Annotation

## Statement

The ecosystem shall support experiment metadata and annotations for task, run, and study discovery, classification, filtering, and comparison.

## Rationale

Requirement inventory expansion. Experiments need first-class metadata for discovery and structured comparison.
