# EXP-724 — Participant Trajectory Corpus And Dataset Model

## Statement

The ecosystem shall support first-class trajectory corpora and datasets for participant training, evaluation, replay, and analysis.

## Rationale

Primary-source refresh shows that agent-supporting ecosystems rely on explicit task and trajectory corpora rather than only on individual runs.
