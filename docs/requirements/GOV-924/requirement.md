# GOV-924 — Translation-Path Provenance And Validation

## Statement

Gateway, bridge, and translation processes shall preserve provenance of the translation path, including source and target artifacts, mappings applied, transformations performed, losses or ambiguities introduced, and the validation basis used for the translation outcome.

## Rationale

Interoperable exchange is not trustworthy if the translation path is opaque. Consumers need to know what mappings and transformations occurred and what validation basis supports the translated result.
