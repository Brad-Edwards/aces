# EXP-725 — Trajectory Corpus Lineage, Split, And Source Semantics

## Statement

The ecosystem shall preserve lineage, split semantics, and source semantics for participant task and trajectory corpora, including distinctions such as runtime, simulated, reference, or other declared sources.

## Rationale

Primary-source refresh shows that trajectory corpora need explicit lineage, split, and source semantics to support honest training, evaluation, and comparison.
