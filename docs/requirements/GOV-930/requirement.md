# GOV-930 — Container Image Supply Chain Policy

## Statement

The ecosystem shall define container image supply-chain policy for published images, including approved base-image expectations, digest pinning where appropriate, vulnerability scanning, and exception handling.

## Rationale

Imported from the superseded governance backlog before deleting the old governance repo. Container-backed runtime and backend surfaces require explicit image policy when images are published or consumed as project artifacts.
