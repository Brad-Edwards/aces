# DSL-122 — Benchmark Truth And Adjudication Asset References

## Statement

The language shall support references to benchmark truth assets, hidden evaluation assets, gold standards, and adjudication assets where tasks or experiments require them.

## Rationale

Primary-source refresh shows that benchmark truth assets and adjudication assets are distinct from public task statements and need an authored reference surface where they are part of the experiment design.
