# EXP-723 — Participant Trajectory Model

## Statement

The ecosystem shall support first-class participant trajectory records capturing ordered interactions such as actions, observations, tool interactions, state changes, feedback, and outcomes.

## Rationale

Primary-source refresh shows that stepwise participant trajectories are first-class experiment artifacts for replay, evaluation, and learning rather than incidental logs.
