# GOV-929 — Release Artifact Signing

## Statement

The ecosystem shall sign release artifacts or provide equivalent verifiable integrity and authenticity evidence for versioned releases intended for external consumption.

## Rationale

Imported from the superseded governance backlog before deleting the old governance repo. Module-level signing exists as an implementation concern, but externally consumed releases need an explicit release-surface authenticity requirement.
