# SEM-221 — Participant Reference Trajectory And Demonstration Semantics

## Statement

The ecosystem shall define explicit semantics for participant reference trajectories, demonstrations, replay assets, and their relationship to public scenario meaning, live execution, and evaluation.

## Rationale

Primary-source refresh shows that reference trajectories and demonstrations are distinct from both public scenario definition and live execution history and need explicit semantic treatment.
