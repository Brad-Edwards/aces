# SCE-001 — Broad ATT&CK Technique Coverage

## Statement

The scenario library shall achieve substantially broader ATT&CK technique coverage, growing from the current ~15 techniques toward coverage comparable to established platforms (CALDERA: 200+, Atomic Red Team: 261 techniques).

## Rationale

Current 5-7% ATT&CK coverage is insufficient for meaningful security validation or agent benchmarking. Coverage gaps leave entire attack categories (cloud, mobile, containers) untestable.
