# ASR-510 — Multi-Role Participant Assurance Coverage

## Statement

The ecosystem shall maintain assurance coverage across adversarial, defensive, non-adversarial, autonomous-service, and mixed-control participant roles.

## Rationale

Requirement inventory expansion. Assurance should cover the full participant role space rather than only one class of actor.
