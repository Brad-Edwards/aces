# ASR-507 — Participant Conformance Corpus

## Statement

The ecosystem shall maintain conformance fixtures and negative-path cases for participant contracts and participant feature declarations.

## Rationale

Requirement inventory expansion. Participant behavior claims need executable conformance evidence rather than documentation alone.
