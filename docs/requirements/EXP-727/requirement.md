# EXP-727 — Verifier, Judge, And Reward Model

## Statement

The ecosystem shall support verifier, judge, and reward models as first-class experiment components distinct from authored tasks, participant trajectories, and live execution state.

## Rationale

Primary-source refresh shows that verifiers, judges, and reward models materially shape participant evaluation and must be modeled distinctly rather than hidden inside one benchmark harness.
