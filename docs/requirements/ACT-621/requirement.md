# ACT-621 — Participant Reference Trajectories And Demonstrations

## Statement

The ecosystem shall support participant reference trajectories, demonstrations, and replay assets distinct from public scenario contracts, live execution histories, and derived evaluations.

## Rationale

Primary-source refresh shows that reference traces and demonstrations are distinct ecosystem assets for training, replay, and evaluation and should not be collapsed into live run history or scenario meaning.
